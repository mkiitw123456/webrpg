# 小葉物語 — 四職業帳號版

本次更新：+1～+15 強化、隊伍等級副本、裝備商店、劍士／弓箭手／法師／盜賊、帳號登入與 PostgreSQL 存檔，以及 CC0 音樂音效。

- 執行 npm install、npm run dev；本機帳號與角色會保存在 .local/accounts.json（已排除 Git）。
- 正式後端需 DATABASE_URL，使用 TLS PostgreSQL（目前 Neon 免費方案）。帳號不分大小寫，3～24 個英數字或底線；密碼 8～128 字元，可與其他帳號相同，以隨機鹽值及 scrypt 雜湊保存。
- 註冊時選職業；同一帳號同時只能一個裝置連線，可由設定頁登出。重啟後請重新登入；舊訪客角色不會自動綁定到新帳號。
- 存檔每 2 秒檢查一次，有變動才寫入。玩家與未結算金幣遊戲以同一份 checkpoint 原子保存；正常停止會再保存一次。突然斷電／強制終止可能回退最近約 2 秒進度；資料庫中斷時暫停遊戲經濟操作。仍採單一後端實例。
- 角色、物品、金幣、技能與強化結果保存；重啟後回村、隊伍重新建立。未配對硬幣房退款；已配對局及強化會接續判定。
- 村莊 M 開啟武器裝備商店，或點擊装備商人；各職業新手武器免費補領且不能出售。持有同款限一件；出售後可再次拾取。販賣需未穿戴且未鎖定。
- 副本入場等級＝round((最低等級+最高等級)/2)，當次副本固定。怪物 HP、傷害、EXP、金幣隨等級提高，裝備掉率從 25% 隨每級增加 2 個百分點、最高 80%；首殺保證職業武器。
- 弓箭手：J 普通射箭／K 二連箭／L 貫穿箭。盜賊：J 投鏢／K 二連鏢／空中再按跳躍二段跳（L 顯示被動）。法師：J 冰凍術／K 火球／L 大範圍奇蹟。劍士保留原有技能。
- BGM 與音效分別調音；第一次按鍵或點擊後播放，受傷無音效。音樂與素材來源見 public/audio/CREDITS.md，採 CC0 授權並隨前端部署。
