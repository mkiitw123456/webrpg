# 小葉物語 — 村莊與隊伍副本

Vite + 原生 JavaScript + Phaser 3 + Node.js 多人遊戲。場景、角色、所有裝備 ICON、掉落物與技能特效由程式生成，打擊音效使用 Web Audio 合成，無外部美術或音效素材。

## 本機執行

Node.js 22.12 以上：

```sh
npm install
npm run dev
```

開啟終端顯示的網址（通常是 http://localhost:5173）。這個命令會一起啟動前端與多人服務；WebSocket 無法使用時會自動使用 HTTP 同步備援。

要測試兩人組隊，請另開一個空白分頁，再輸入相同網址。每個分頁使用獨立的訪客角色。不要使用瀏覽器「複製分頁」功能，因為部分瀏覽器會一併複製角色憑證。

同一區域網路的朋友，可使用終端列出的 Network 網址連入。遠端網友需要連到同一個已公開部署的多人伺服器。

| ← / → | 移動、轉向 |
| Space | 跳躍，提早放開可小跳 |
| J | 普攻，可按住連續攻擊 |
| K | 翠葉劍氣，10 MP |
| L | 旋風斬，18 MP |
| R | 藥水，恢復 60 HP / 30 MP |
| E | 穿戴裝備 |
| I | 背包 |
| C | 技能書 |
| P | 組隊與副本 |

設定頁可重新指定字母、數字、方向鍵和空白鍵。重複按鍵會提示衝突。按鍵與音量存於瀏覽器 localStorage，重新整理仍保留。Esc 固定為關閉，輸入角色名稱時不觸發遊戲操作。

打擊音效只在攻擊命中怪物時播放，玩家受傷無音效。音量設為 0% 可靜音；瀏覽器需要一次點擊或按鍵才允許播放音效。

## 村莊、組隊與副本

1. 新角色預設位於小葉村，村莊不生成怪物並緩慢恢復生命。
2. 在「組隊與副本」介面修改名稱、建立隊伍。
3. 隊長邀請村莊內的旅人，對方按接受後才加入，隊伍最多 4 人。
4. 隊長按「全隊進入微風草原」，全員一起切換至同一個專屬副本。單人隊伍也可出發。
5. 每次出發產生新的副本 ID。其他隊伍無法看見、攻擊或拾取本隊副本中的怪物與掉落。
6. 怪物血量、技能消耗、冷卻、掉落與經驗由伺服器管理；同副本在線隊員共享擊殺經驗。
7. 戰利品由第一位靠近的玩家拾取一次。怪物 5 秒後重生，角色倒下 2 秒後在同副本入口復活。
8. 隊長可以全隊回村；隊員可離隊並自行回村。離線會離隊回村，隊長離線時自動交接。

副本中的選單不暫停世界，請在安全位置整理背包。HTTP 連線未正常關閉時，伺服器最多約 15 秒後判定離線。

## 裝備與贈送

「穿戴裝備」顯示武器、上衣與能力值；「背包」顯示未穿戴裝備及藥水。穿戴後移至裝備欄，卸下後回背包。所有裝備及藥水都有各自的像素 ICON。

回村莊後，在背包選物品並按「贈送」，選擇另一位旅人與數量，再送出邀請。對方在「物品贈送」接受後，伺服器才原子移轉物品。支援拒絕、取消與 60 秒逾時；離線自動取消，不會先扣物品。

已穿戴裝備不能贈送，正在贈送的裝備不能再穿戴。藥水交易未完成前暫時禁止喝藥，避免庫存變動。這一版同款裝備每人限持有一件，裝備一次移轉一件，藥水可指定數量。

## 新怪物、強化與金幣遊戲

隊長在「組隊與副本」選擇目的地：微風森林（史萊姆、野豬）、星晶洞窟（蝙蝠、巨像）、巨菇秘境（菇菇）。三張地圖有不同背景、平台布局與地板素材；全隊進入同一份專屬實例，其他隊伍即使選同地圖仍彼此隔離。五種怪物具有不同血量、速度與傷害。擊殺分別掉落鐵劍、赤銅巨劍、月影長衣、獠牙鎧甲與星晶大劍（首殺固定鐵劍）。同款裝備仍限一件。九款裝備皆使用程式生成的像素 ICON。場景深度固定為天空 -40、雲 -30、山 -20、樹 -10、建築 0、平台 2、怪物 4、玩家 5。

村莊按 **F** 開啟強化工坊，或在裝備／背包按「強化」。品階是裝備難度，與角色等級分開。費用為 `25 × 品階 × (目前強化 + 1)²`；例如木劍 +0 費用 25，+1 費用 100，+2 費用 225。每段用 350ms 顯示藍色成功條與橘色失敗條的增量，再停留 500ms 才擲下一段；每次成功增量有 10% 機率變成原始擲值的 2 倍，以亮藍色區段保留標記；先到 100 的一方獲勝，同步跨線以到達終點的比例判定，同時到達隨機平手裁決。品階及強化越高，藍條增量越少、橘條越多；實際範圍在面板顯示。成功 +1（最高 +10），每級武器攻擊 +3／防具防禦 +2；費用不退。目前強化等級不超過 +6 時，失敗不掉級、不毀裝；目前 +7～+9 若失敗，先停留 500ms 再進入第二輪：上方橘條代表保留裝備（每次 +8～22），下方紅條代表爆裝（每次 +5～18）。橘條先滿只失敗，紅條先滿則從背包、穿戴欄與強化紀錄移除該裝備；第二輪也遵守 350ms 增長＋500ms 停留。強化中鎖定裝備、禁止全隊出發，關閉面板或斷線仍會完成。贈送會保留強化等級。

村莊按 **B** 或點擊「幸運葉」建築開啟金幣遊戲館。F／B 也能在設定自訂，舊按鍵設定會保留；若新預設鍵已被使用，會分配空閒鍵。

- **紅黑綠**：每 60 秒一局，第 48 秒封盤。橫向數字帶以 1–7 為紅、8–14 為黑、0 為綠；紅黑返還投注的 2 倍，綠返還 14 倍，均含本金。三欄即時顯示玩家姓名、累計下注、我的下注及各色總額，支援快捷金額。封盤後伺服器隨機產生開獎數字、6–10 圈、約 6.5–11.5 秒的轉動時間及減速曲線，所有玩家按伺服器時間顯示同一動畫，準確停在派彩數字。轉動參數只在封盤後公開；啟動與停止各有合成音效，音量共用設定，關閉面板不播放。每局轉動開始時刻不同，結算仍在第 60 秒。
- **丟硬幣**：房主設定金額與正反面，對手投入相同金額並自動選另一面，清單可選 Join 或 View。Join 先打開再次確認框，確認才扣款並配對；雙方顯示完整玩家 ID、姓名與正反面。配對後中央環形進度倒數 10 秒，接著播放 4 秒拋幣翻轉落地，公平硬幣决定勝者、全額派彩。View 不扣款，可同步觀戰或查看結果。完成的房間留在清單 30 分鐘才移除（目前仍是伺服器記憶體，重啟會清空）。未配對可取消，2 分鐘或房主離線自動退款。配對後不允許取消，離線仍結算。
- **賭池**：每 60 秒結算，第 48 秒封盤。封盤後伺服器決定加權勝者、位於其區域內的停點、6～10 圈推力、6.5～11.5 秒轉動時間與減速曲線。前端逐幀顯示同一條連續軌跡，停輪與派彩使用同一結果，不再用無限旋轉動畫突然切換角度。可多次投入，面板合計各玩家占比並繪製輪盤；抽籤依金幣權重，勝者拿走全部。少於 2 位不同玩家退款。開獎後暫時顯示上一局輪盤與勝者，再顯示新局。

每次投注限 1–100,000 整數金幣；轉盤／賭池每人每局最多 20 筆。所有扣款、鎖定、加權抽籤與派彩皆在伺服器完成，使用 Node crypto 亂數。這些是遊戲內金幣，沒有現金支付或兌換。已接受投注離村／離線後照常結算；伺服器重啟仍會清空記憶體資料，尚未實作持久化帳本。

## 驗證

```sh
npm test
npm run build
npm run preview
```

測試包括按鍵衝突、技能與装備規則、隊伍邀請、多人換圖、副本隔離、重複拾取、交易鎖定與原子移轉、斷線交接、實際三個 WebSocket 連線，以及 HTTP 同步備援。`npm run preview` 也啟動本機多人服務。

## 部署

這個實作的前端可部署 Vercel：Framework 選 Vite，Build Command 使用 `npm run build`，Output Directory 使用 `dist`。

多人狀態由獨立、持續執行的 Node 程序持有，不能只上傳 `dist` 就完成多人部署。在支援長時間 Node 程序的環境執行：

```sh
npm install
npm run server
```

多人伺服器預設連接埠為 8787，可使用系統環境變數 `PORT` 修改。以 HTTPS/WSS 反向代理公開該服務，並設定：

- 伺服器 `ALLOWED_ORIGINS`：前端完整來源，例如 `https://your-site.vercel.app`；多個來源以逗號分隔。
- Vercel 前端 `VITE_GAME_SERVER`：例如 `wss://game.example.com/multiplayer`。修改後需要重新建置前端。

WebSocket 與 HTTP 備援使用同一個多人服務、同一份世界資料。前端為 HTTPS 時，後端也需要 HTTPS/WSS。

目前後端是單一程序的記憶體世界，未接資料庫或正式帳號。重新整理同一分頁可恢復角色，伺服器重啟會清空角色與物品，離線超過 24 小時也會回收角色。正式營運前需要持久化、帳號驗證、完整伺服器移動物理與部署擴展；目前的移動使用客戶端 Arcade Physics 加上伺服器位移範圍檢查。

## 程式結構

- `server/World.js`：玩家、隊伍、副本、怪物、掉落、交易與戰鬥規則。
- `server/Forge.js`：強化扣款、裝備鎖定與雙條競速結果。
- `server/Casino.js`：三種金幣遊戲、退款與派彩。
- `src/shared/progression.js`：怪物屬性、掉落及強化難度與費用。
- `src/ui/WorkshopUI.js`：強化面板、遊戲房間、輪盤、勝率與結算畫面。
- `server/hub.js`：WebSocket / HTTP 傳輸、Origin 驗證、訊息大小與頻率限制。
- `server/index.js`：獨立部署用伺服器入口。
- `vite.config.js`：本機開發與預覽的多人服務整合。
- `src/network/GameClient.js`：連線、同步、重連與備援。
- `src/systems/Controls.js`：自訂按鍵與保存。
- `src/systems/CombatAudio.js`：合成命中音效與音量。
- `src/systems/RPGState.js`：共用角色數值、裝備與技能。
- `src/shared/world.js`：共用地圖與攻擊範圍規則。
- `src/assets/itemIcons.js`：所有物品像素 ICON。
- `src/assets/generateTextures.js`：場景與角色動畫素材。
- `src/scenes/GameScene.js`：村莊／副本渲染、玩家與連線同步。
- `src/entities/Player.js`：本地角色移動與武器。
- `src/entities/Enemy.js`：伺服器怪物的畫面呈現。
- `src/ui/GameUI.js`：獨立裝備、背包、技能、隊伍、贈送、設定介面。

新增模組：`src/shared/maps.js`（地圖與棲地）、`src/assets/mapScenery.js`（像素環境）、`src/shared/roulette.js`（數字帶與連續減速）、`src/ui/RouletteUI.js`（即時下注表與動畫）。

`src/ui/ForgeUI.js` 負責分段強化、亮藍加倍標記及爆裝競速；`src/ui/CoinUI.js` 負責房間清單、再次確認、即時倒數與拋幣動畫。

金幣採用共用程式生成的 32×32 像素圖：金色鑄邊、葉紋正面、星紋反面；遊戲掉落金幣、硬幣席位、清單及拋幣動畫共用 `src/assets/coinIcon.js`。賭池動畫由 `src/shared/pool.js` 與 `src/ui/PoolUI.js` 同步處理。
